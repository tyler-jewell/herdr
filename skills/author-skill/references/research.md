# Research the subject

Start at the URL the user named. Read that page. Record every source repository it links as its own spec, dataset, or code.

Open only those repositories. List the tree. An official skill is a `SKILL.md` that org publishes for this subject. An official plugin is a plugin manifest that same org publishes for this subject. A similar skill in another org is third-party. Say so, and do not vendor it as official.

Write down the URL and the revision you read (tag or commit). A later change updates that pin in the same edit as the skill. Do not follow a link from a fetched page to a host the official page did not name.

If the official tree has no skill and no plugin, load [write.md](write.md). If it has one, load [vendor.md](vendor.md) and stop.
